# Design samples (reference only, not in git)

The owner supplied five reference images for the v1 layouts (PRD §7.1). They show
other people's photos and another brand's designs, so they are **not committed**
(this repo is public), never shipped in the app and never used in marketing. Ask
Clement for them if you need to compare; drop them here locally (gitignored).

The in-app gallery renders our own layouts with demo data (`src/domain/demo.ts`).

| Expected file | Design | What the sample shows |
|---|---|---|
| `poster-classic.png` | Poster Classic | White sheet. Condensed bold title, date under it. Square dark (Graphite-like) map with orange route. Bottom right: NAME #BIB, a rule, then three stats (42.195 KM · 04:34:44 TIME · 06:31 /KM). |
| `big-time.webp` | Big Time | Full-bleed photo. Top: name + #bib left, "City, Country" + dd.mm.yy right. Thin white route upper third. Huge ghosted finish time mid-lower, rule, race title. Bottom bar: Distance left, Pace right. |
| `editorial.webp` | Editorial | Full-bleed photo. Top: name + #bib left, country + year right. Middle: rule then "26 APRIL", then race title on two big lines (second right-aligned). Bottom bar: Distance · Pace · Time. |
| `mono-tech.png` | Mono Tech | B&W photo, neon yellow route, yellow monospace text: "LOCATION: / CITY, COUNTRY" top centre; "RACE: …", "PARTICIPANT: … | BIB: …", "DISTANCE: … | TIME: … | PACE: …" lower centre. |
| `duo.webp` | Duo | Full-bleed photo of two runners. Top: city/country left, day month/year right. Big two-line race title bottom-left, rule, then two columns: name, big time, pace (left runner left-aligned, right runner right-aligned). |
